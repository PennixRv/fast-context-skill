# 上游 v1.3.2 协议对照

## 资料范围

对照原始 `SammySnake-d/fast-context-mcp` 的公开 `v1.3.2` `src/shared.mjs` 与 `src/core.mjs`，并与本仓库 `scripts/lib/core.mjs` 的 `0.1.5` 打包实现比对。仅将上游视为互操作性证据，不继承其安全边界较弱的处理。

## 差异

| 维度 | 上游 v1.3.2 | fork 0.1.5 | 本任务选择 |
| --- | --- | --- | --- |
| 终态策略 | 最后有效工具回合后追加 `You have no turns left... final ANSWER` 用户消息 | 仅从终态工具定义中移除 `restricted_exec` | 恢复显式 force-answer，且终态定义仍只含 `answer` |
| 系统提示词 | 详细说明受限工具、调用例子、严格 XML、空 `<ANSWER>`、结果数 | 九行压缩提示词，只有简短格式说明 | 恢复最小协议例子、精确无结果标记和结果上限，不恢复冗长策略文本 |
| 工具调用解析 | 使用 JSON 修复及 `restricted_exec` 参数回收 | 只接受完整、有界 JSON，并仅允许一次格式重试 | 保持 fork 的严格解析和单次有界重试 |
| 最终答案解析 | 忽略不安全路径，保留 ranges；支持响应/会话证据回收 | 对无范围、拒绝路径、无效范围静默跳过 | 保持本地严格拒绝，但把拒绝转为结构化 `truncated` 而非伪完整无结果 |
| 无结果语义 | 空 `<ANSWER></ANSWER>` | 无文件标签即视为完整零候选 | 接受精确 `<no_results/>` 与既有空 `<ANSWER></ANSWER>`；其他无候选格式为协议无效 |
| 流式兼容字段 | `Accept-Encoding: identity` 与完整 Connect Go `User-Agent` | 缺少或缩短该固定字段 | 恢复这两个不含设备或凭据的固定字段；不恢复主机名、CPU、TLS 降级或 Sentry 追踪头 |
| 失败输出 | 可带原始响应、绝对项目路径和上游异常文字 | 固定 `FC_*`，不输出原始正文 | 保持固定 `FC_*` 与无敏感诊断 |

## 选择理由

上游四次真实成功说明 force-answer、完整示例和无结果规则值得恢复为最小兼容层；它不能证明上游完整实现适合本组件。上游的修复 JSON、回收 prose、会话拼接和原始响应输出将把不可信远端内容重新引入结果面，违背本组件的 PathGuard、固定诊断和零敏感输出合同。因此仅移植可单元测试的对话约束和提示词信息，所有候选仍由 fork 的本地范围复核接受。
