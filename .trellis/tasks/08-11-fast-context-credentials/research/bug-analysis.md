# 缺陷复盘：凭据边界与有效 envelope 的工具格式

## 1. 根因类别

- **类别**：B，跨层契约；D，测试覆盖缺口；E，隐式假设。
- **具体原因**：CLI 将“可用凭据”等同于显式环境变量，丢失了原始 MCP 已验证的 WSL Devin 登录态路径。修复后，真实服务可返回严格有效的 Connect envelope，但其工具调用标签并不总是完全符合本组件未明确提示的紧凑语法。旧的离线夹具只覆盖规范输出，不能区分 envelope、工具标签和参数 JSON 三个边界。

## 2. 修复收敛过程

1. 仅接入固定 Devin TOML 路径后，`FC_KEY_MISSING` 消失，但真实探针仍报 `FC_PROTOCOL_INVALID`：这排除了凭据读取是唯一根因。
2. 对齐认证协商头后仍失败：这排除了该请求头是工具格式失败的根因。
3. 受控、无内容的结构分类证明 Connect decoder 接受响应并看见工具标记，问题位于工具标签/参数格式。
4. 明确提示和 ASCII 格式空白兼容改善了部分响应，但远端模型仍可能输出不合规参数。最终采用仅针对“有效 envelope 但本地工具标签/JSON 不合规”的同预算一次重试；第二次仍不合规即稳定失败关闭。

## 3. 预防机制

| 优先级 | 机制 | 具体动作 | 状态 |
| --- | --- | --- | --- |
| P0 | 架构 | 显式密钥优先；固定 Linux Devin 子进程隔离读取；无 shell、大小和时限边界 | DONE |
| P0 | 测试 | 401/403、5xx、超时、网络、协议、禁用、发现 fixture、包安装入口与同预算重试 | DONE |
| P0 | 契约 | security spec 固化来源顺序、错误矩阵、工具格式、一次重试和禁止项 | DONE |
| P1 | 运行验收 | 根仓库以保留的现实查询复核候选路径，不以本组件任务替代根 Issue 关闭 | PENDING ROOT |

## 4. 系统性扩展

- 任何未来外部模型协议都必须分别测试传输 envelope、模型指令格式、参数 JSON 与本地执行边界；不得用一个泛化错误码掩盖这些阶段。
- 远端模型输出可不稳定，但本组件不得以 JSON 修复、原始 response 回传、未知工具名或路径放宽换取成功率。
- 所有新的凭据来源都应遵循“固定来源、受控子进程、私有短管道、无持久化、失败关闭”的模式；不得扩大到桌面状态库或调用方任意路径。

## 6. 终结轮补充

真实 Devin 探测显示，模型可以连续给出三次有效的本地工具调用而未主动结束。根因是原有三轮上限同时承担了本地工具与最终 answer，提示词本身不能成为资源边界。修复保留三次本地工具执行上限，增加同一 deadline 内的第四次 answer-only 请求，并通过 tool definition 与本地响应检查双重约束。离线回归验证该终结 definition 不含 `restricted_exec`，真实 WSL CLI 探测返回一个本地复核候选；未增加超时、命令数、原始响应读取或远端内容透传。
